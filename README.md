# Tugas Pemrograman Mobile 2 - Tontonin ( Aplikasi Penyedia Film )



## Deskripsi Aplikasi
Sebuah tampilan Aplikasi Penyedia film yang di dalamnya terdapat beberapa informasi film, jadwal, hingga pembookingan kursi.Dibuat untuk memenuhi tugas mata kuliah Pemrograman Mobile 2.

## Fitur di dalamnya
- Fitur Log in dan daftar
- Dashboard Pilihan Film
- Lokasi 
- Detail cardview yang menampilkan keterangan lebih lanjut terkait film
- Detail deskripsi
- Pemilihan tanggal dan Bookingan Kursi

## Cara Menjalankan Sistem
1. Pastikan Flutter sudah terpasang
2. Clone repository ini
3. Jalankan perintah berikut:

```
flutter pub get
flutter run -d chrome
```
